# Jun Project Charter

## 프로젝트 정의

`WP_4th`는 Unreal Engine 5.7 기반의 C++ 전투 프로토타입 저장소이며, 현재는 Apex 스타일 FFA 전투와 슈터 계열 시스템을 중심으로 확장 중이다.

## Jun 작업 목표

- Jun 기준의 문서 작업 하네스를 먼저 세운다.
- 현재 코드 구조를 기능 단위로 다시 읽을 수 있게 정리한다.
- 이후 구현 작업이 문서와 연결되도록 흐름을 만든다.
- 자기장 시스템과 데스매치 게임모드를 병렬 작업에 안전한 범위로 정리하고 구현한다.

## 현재 범위

- 자기장(링) 시스템
- 데스매치 게임모드
- 게임 규칙과 매치 흐름 제어
- 스폰, 축소, 데미지, 승패 처리 같은 서버 주도 로직

## 이번 단계 성공 기준

- Jun 문서만 읽어도 작업 기준을 이해할 수 있다.
- 다음 세션에서 바로 이어서 작업할 수 있는 상태다.
- 백로그와 세션 로그가 최소한의 운영 도구 역할을 한다.
- Jun 담당 범위인 자기장 시스템과 데스매치 게임모드의 목표와 책임이 문서에 명확히 드러난다.
- 캐릭터 담당자, 무기 담당자와 나중에 합칠 때 충돌이 적은 구조 방향이 드러난다.

## 다음 마일스톤

1. 시스템 구조 파악
2. 자기장 시스템 요구사항 정리
3. 데스매치 게임모드 요구사항 정리
4. 두 시스템의 상세 설계 문서 추가
5. 구현 및 검증 루프 정착
